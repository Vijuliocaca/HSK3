# Sugerencias recibidas

Aquí se apuntan las sugerencias que llegan desde Ajustes → Sugerencias (ver `sugerencias()` en `index.html`). `IDEAS.md` es solo para ideas propias.
Cada una pasa por un estado: **Nueva** → **Aceptada** (se hará) → **Hecha** (con la versión `hsk3-vNN`) o **Descartada** (con el motivo, para no volver a darle vueltas).

Formato (pega el texto que llega por compartir y añade el estado):

```
### [Estado] Tipo · Dónde · Detalle
Qué ha pasado / Esperaba / Se repite
(fecha; versión, pantalla, navegador)
Decisión: …
```
